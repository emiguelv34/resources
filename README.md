## Sp'26 CS104 Resources Repo

This repo will contian lab code, homework **tests**, and other class material.  For example, each week we will populate a subfolder (e.g. `lab1`, `lab2`, etc.) with any necessary files for the lab.

### One Time Setup

Clone this repo (assuming you've joined the `classroom-starter` repo and setup your SSH key (see **lab0**):

```bash
git clone git@github.com:usc-csci104-spring2026/resources
```

### Weekly

Once cloned, then you can simply run `git pull` each week to pull in updated folders and files that we have committed/pushed.
